# Marzan Tasnim Oyshi Portfolio

A modern one-page research portfolio for Marzan Tasnim Oyshi, built with React and Vite.

## Overview

This portfolio presents research interests, projects, publications, skills, and contact links with an immersive visual design inspired by climate, sustainability, data visualization, and AR/VR environments.

## Tech Stack

- React
- Vite
- Plain CSS

## Features

- Responsive one-page portfolio layout
- Animated immersive hero banner
- Theme switcher with multiple color palettes
- Publications timeline grouped by year
- Expandable publication abstracts
- Research interests, projects, skills, and contact sections

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

## Project Structure

```text
src/
  App.jsx
  App.css
  index.css
  publications.js
  assets/
```

Publication data is stored in `src/publications.js` so it can be updated easily.
